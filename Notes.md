Project title:			Meteo station/ Muotathaler Wetterschmöcker

Requirements:			Temperature measurement & display on screen
						Humidity measurement & display on screen
						Atmospheric pressure measurement & display on screen

Optional requirements:	Air pressure (barometer)
						Screen brightness with potentiometer on Leguan
						Timer with buzzer
						Clock (via WIFI ping)
						API to MeteoSwiss/ Meteoblue for wheather alerts

Developement modell:	Agile

Helpful stuff:
Leguan dev' guide:		https://leguan.ti.bfh.ch/index.html
Online gantt chart:		https://www.onlinegantt.com/#/gantt

Milestone 1 (Week 5)
1) Partial Requirements Specification (SRS): Rough specification of the project to implement
2) Source code of the Minimal Viable Product (MVP): Demo of a functional prototype working
3) WBS + Gantt diagram: Timeline, milestones, and resource allocation.
4) Progress report: Summary of activities so far (powerpoint form is also possible)

Milestone 2 (Week 10)
1) Second version of the working software: Improvement of the MVP
2) Test plan and partial test results: Evidence that the delivered features pass tests
3) Updated SRS: Comments on source code, initial user manual
4) Progress report: Summary of development, testing, and outcomes

Final delivery (Week 15)
1) Fully tested source code: Complete and verified software.
2) User Manual Guide for end-users.
3) Final progress report: Summary of development, testing, and outcomes.
4) High-Level Design: Flowchart, Finite State Machine, UML diagrams (class, use-case sequence), Architecture and module breakdown.
5) Finalized SRS document: Final specification of the implemented project
